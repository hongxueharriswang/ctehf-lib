# v0.2.0 Migration Guide

## Breaking changes

### `LearnerState.DC` now returns three-constituent composite

**Before (v0.1.0):** `DC = mean(competencies + knowledge)`

**After (v0.2.0):** `DC = w_disc*DC_disc + w_prof*DC_prof + w_comp*DC_comp` (Section 3.2.3)

Numeric values differ. Code that compared `DC` to a hardcoded baseline
must be recalibrated. The new `DC_decomposed` property returns the three
constituents separately.

### `governance.is_admissible` and `filter_admissible` are deprecated

**Before (v0.1.0):** pointwise filter on pedagogical actions.

**After (v0.2.0):** trajectory-monitoring daemons (`daemons.GovernanceDaemons`).
The pointwise filter is retained for backward compatibility but emits a
`DeprecationWarning`. Section 5.1 of the revised paper explicitly supersedes
the filter with the daemon formulation.

## New features

- `dc.py` — DC three-constituent decomposition
- `triggers.py` — ECA trigger sets T_ped and T_safety
- `daemons.py` — governance trajectory daemons
- `embeddings.py` — E_learner, E_action, E_artefact
- `hybrid.py` — HybridDynamics + Theorem 3.1 assumption checks
- `free_energy.py` — precision prior + variational free energy
- `ethical.ethical_competence_via_precision` — free-energy variant of EC

## Migration examples

### DC

```python
# Before
dc = state.DC  # mean(competencies + knowledge)

# After — same call, new formula
dc = state.DC  # w_disc*DC_disc + w_prof*DC_prof + w_comp*DC_comp
decomp = state.DC_decomposed  # dict with DC_disc, DC_prof, DC_comp
```

### Governance

```python
# Before
from ctehf_ai import is_admissible
if is_admissible(action):
    ...

# After
from ctehf_ai import GovernanceDaemons
g = GovernanceDaemons()
result = g.run(trajectory, perf_ai_traj, perf_indep_traj, ai_action_log)
if result["d_dual_prep"] == "noop" and result["d_ethics"] == "noop":
    ...
```
